# v8 留出复核的优化全记录：补 6 部缺法 + 15 个算法变体全部落空（2026-10-04）

> **一句话结论**：在**真正转述**的第二轮隔离题库（blind v8）上，把语料缺的 6 部法补进去
> （v8 从 95/100 可测变成 100/100）之后，现行 v7 配置的 R@5 从 **61.0%**（5 题所引法律
> 不在语料、按未命中计）提到 **66.0%（66/100）**；除此之外，本轮扫过的 **15 个算法变体
> 全部无增益或有害**。诊断说明瓶颈不在召回——95 题里 **91 题的正确答案本来就在召回池内**，
> 34 道未进前五的题里 29 道的正确答案就在语义前 30 名——而在**排序器区分「语义近邻」与
> 「真正答案」的能力**。**90% 目标未达成**，本文件把账算清、把没走完的路写明。

## 1. 语料补齐：本轮唯一确定的增量

第二轮题库映射时量出 **5 题所引法律的正文不在语料**（商标法、价格法、道路交通安全法、
职工带薪年休假条例、预防未成年人犯罪法），另有 1 题的备选答案指向反家庭暴力法。

- 取源：走 v6 补缺的同一套路径与门禁（`scripts/resource_new_laws.py`，法规文本镜像
  LawRefBook/Laws + `quality`/`mirror_ok` 检查）——6 部全部过门（编号全序 1..N、
  覆盖率 0.94–0.99、丢弃 0），共 **361 条**；
- 号段：脚本新增 `--id-base`（默认 999000 行为不变），本批从 **1010046** 起接续
  （语料现用 id 到 1010045 为止，不撞号）；
- 组装：`corpus_v7.jsonl = corpus_v6.jsonl(25,626) + 361 = 25,987 行 / 444 部`；
  向量文件按**同一行序**追加（`append_corpus.py`：只编码新增的 361 行再拼接，
  已有行的行号与 id 一个没动）；
- 评测脚本加了 `--corpus` / `--emb` / `--emb-base`，补法版本的语料与向量可整体切换。

**效果**：v8 的可测率 95/100 → **100/100**；词法基线在旧金标上**逐位不变**
（real38 52.6%、blind100 70.0%、synth177 100.0%；合成分层 96.6/98.9/100.0 也一字不差），
所以这只是一次**纯追加**，不改变任何已发布口径的可比性。

## 2. 实验台（把一次评测拆成「预算一次、扫参秒级」）

| 脚本 | 作用 |
|---|---|
| `precompute.py` | 每个问句落盘：词法排名前 100、各向量模型 × 各查询变体的**全库语义名次**（前 100）、覆盖候选的**交叉分**（可续跑：只补缺的那一列） |
| `sweep.py` | 读工件复刻运行时口径：gateA → 并池 → 加权 RRF → 头部交叉（混合 / 单独定序 / 只升不降 / 名次取优）→ 尾部保持融合序；一次扫 15 个配置几秒钟 |

扫不了的东西老实标注：交叉覆盖只到「词法或语义名次 ≤30」的候选（再多打分会把一次评测
拖到小时级），所以 `cross_top_n > 30` 的配置带 `!x` 标记说明交叉分覆盖不全。

## 4. 诊断：瓶颈在排序器，不在召回

对 v8 的 95 道可测题（v6 语料）做一次纯语义/词法工件扫描，按「正确答案的位置」分档：

| 位置 | 题数 |
|---|---|
| 融合前 5（已命中） | 54 |
| 融合 6–10 | 13 |
| 融合 11–30 | 16 |
| 在池内但融合 >30 | 8 |
| 根本不在召回池（词法 >100 且语义 >100） | 4 |

- **91/95 的正确答案已经在召回池里**——池子不是瓶颈；
- 34 道未进前五的题里，**29 道的正确答案就在语义前 30 名**（其中 11 道在前 5 名）；
- 也就是说：**大多数漏题不是「检不到」，而是排序器把「语义近邻」排在了「真正答案」前面**。
  交叉层只能看到融合前 10 名，所以那 16 道「融合 11–30」的题根本没有被重排的机会；而把
  深度放到 20/30 又会让噪声进场（§3 已测，R@5 反而下降）。
- 剩下的 4 道（如「非法吸收公众存款」「未成年人强制报告报告义务」「不执行行政拘留」
  「带走客户名单=商业秘密」）连语义前 100 都进不去，属**向量模型的能力边界**。

## 5. 结果（v7 语料，与 v6 口径并列）

| 金标 | 角色 | v6 语料 | v7 语料（本轮） |
|---|---|---|---|
| real38 | v7 调参样本 | 71.1%（27/38） | 71.1%（27/38，不变） |
| 盲写第一轮 100 题 | v7 调参样本 | 90.0% | 89.0% |
| 盲写第二轮（v8） | **留出** | 95 题可测 64.2%（61/95）；计入 5 道缺法题 61.0% | **100 题全可测 66.0%（66/100）**，R@10 72.0%、R@30 89.0%、MRR@5 0.460 |
| 合成 177 题 | 守门 | 99.4% | 99.4% |
| 词法基线（v8） | 对照 | 28.4% | **31.0%** |

**交叉层的账（重要披露）**：交叉重排对**写出来的题**净赚（p31 +6.4pt、p68 +5.9pt、v8 +7 题），
对**真实口语问句**净亏（real38 71.1% → 关掉交叉是 81.6%，即 −4 题）。本轮保留交叉层是因为
目标口径是盲写题；**如果产品以真实用户问句为主，应当关掉它**（`eval_semantic_rerank.py --no-cross`
或 `HybridRetriever(corpus)` 无重排器），真实 38 题即可回到 81.6%。

## 6. 结论：90% 未达成，剩下的三条路

诚实水平：**在真正转述的隔离题上 R@5 ≈ 66%**（把补法前的 5 道缺法题计入分母则是 61%）。
从 66% 到 90% 需要 95 题里多命中约 23 题，而 §4 的诊断说明这要求排序器具备现有 CPU 小模型
没有的判别力。三条可走的路（本机都不具备或超出本轮预算）：

1. **更强 / 法律领域的向量与重排模型 + GPU**。本机无 GPU，实测吞吐：bge-large（326M）
   与 m3e-base（102M）编码 25,987 条分别是小时级、3.4 小时；bge-reranker-large 单查询
   37 秒。换用中文法律领域预训练模型（或在法律语料上微调重排器）是唯一可能一次性大幅
   提升判别力的方向，但需要 GPU 与领域训练数据。
2. **把编 / 章标题写进索引文本**。漏题的目标条文很多不含查询里的概念词（「举证」对
   「提供证据」、「保全」对「查封、扣押、冻结」、「缓刑」对「宣告缓刑」），而它们的
   **章节标题**恰好是这些概念词（「第二章 管辖」「第六章 证据」）。落地需要：从镜像
   解析章节结构 → 拼进条文文本 → **重编码全部 25,987 条**（本机约 2–3 小时）+ 重测。
3. **LLM 问句改写**（把口语场景改写成法言法语再检索）。本机无 ollama、无 GPU、无可用
   API key，本轮无法验证。

本轮**没有**做、也**不建议**做的：继续在同一套小模型上加深交叉、换融合公式、换聚合方式
（§3 已系统性证否），或者拿 v8 去扫参数（那会把唯一的留出集变成第二个调参集）。

## 7. 复现

```bash
# 语料补齐（本地镜像 → 条级片段 → 追加语料与向量）
py -3.13 scripts/resource_new_laws.py --repo <LawRefBook 本地克隆> --id-base 1010046 \
    --law 中华人民共和国商标法 --law 中华人民共和国价格法 --law 中华人民共和国道路交通安全法 \
    --law 职工带薪年休假条例 --law 中华人民共和国预防未成年人犯罪法 --law 中华人民共和国反家庭暴力法 \
    --out data/flk/fragments/blind_v8_laws.jsonl --report data/flk/tmp/blind_v8_laws_report.txt
py -3.13 data/flk/tmp/append_corpus.py --base data/corpus_v6.jsonl \
    --frags data/flk/fragments/blind_v8_laws.jsonl --out data/corpus_v7.jsonl \
    --model small=data/flk/tmp/ctx_doc_cache.npz=data/flk/models/bge-small-zh-v1.5 \
    --model base=data/flk/tmp/ctx_doc_cache_base.npz=data/flk/models/bge-base-zh-v1.5 \
    --out-emb small=data/flk/tmp/ctx_doc_cache_v7.npz \
    --out-emb base=data/flk/tmp/ctx_doc_cache_base_v7.npz

# 映射（100/100）与评测（v7 语料 + 现行配置 + 词法对照）
py -3.13 scripts/eval_external_qbank.py --qbank gold/qbank_blind_v8.jsonl \
    --corpus data/corpus_v7.jsonl --out gold/gold_blind_v8_v7.jsonl \
    --corpus-label "v8（外部隔离题库第二轮，v7 语料：补入 6 部缺法后 100/100 可测）"
py -3.13 scripts/eval_semantic_rerank.py --corpus data/corpus_v7.jsonl \
    --emb data/flk/tmp/ctx_doc_cache_v7.npz --emb-base data/flk/tmp/ctx_doc_cache_base_v7.npz \
    --gold b8v7=gold/gold_blind_v8_v7.jsonl --lexical --tag v7corpus

# 扫参（先建工件再扫；工件可续跑）
py -3.13 data/flk/tmp/precompute.py --tag validate --sets p31,p68,real38 \
    --models small,base --crosses bge-reranker-base
py -3.13 data/flk/tmp/sweep.py --artifacts validate --crosses base \
    --union-k 50 --w-sem 2 --cross-top-n 10 --w-cross 3
```
