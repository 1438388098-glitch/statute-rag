# 真实问句检索改进实验记录（v0.1.1）

> **口径提示（2026-10 追加）**：**§0–§7 全部数字为 v1 语料（14,212 条）口径**；§4b 与 §8 记的是 v3 轮的负结果与修订，除注明外亦沿用 v1 口径并以「v3」显式标注。语料已按法考汇编补全到 v3（25,273 条 / 432 部），同一批问句的 R@5 一度降到 31.6%、经检索侧重标定恢复到 44.7%。**当前口径以 [docs/eval_report.md](eval_report.md) / [docs/metrics.json](metrics.json)（v3）为准**；v3 轮的诊断、修订与负结果见 [docs/retrieval-v3-diagnosis.md](retrieval-v3-diagnosis.md) 与本文 §4b、§8。

> **一句话结论（v1 口径）**：用「法律口语↔法言法语同义词典 + 查询扩展多路召回」这一通用机制，真实问句金标（38 题，百度知道真实提问）上 hybrid Recall@5 从 **26.3%（10/38）提升到 44.7%（17/38，+18.4pt）**，MRR 从 0.180 到 0.312；**合成金标 Recall@5 保持 98.9%、MRR 保持 0.984，零回退**（守门线为回退 ≤2pt）。剩余 21 题未命中如实列出（见 §6），主要卡在纯语义等价与语料解析污染，是 v0.2 向量通道的工作。

## 0. 方法纪律（防过拟合边界）

- **金标不动**：`gold/gold_real_38.jsonl`（38 题）与 `gold/gold_synth_seed20260918.jsonl`（177 题）在全部实验中一个字节未改；评测脚本口径不变（Recall@5 / MRR，k=5）。
- **不做按题调参**：所有改动都是通用机制（数据化的领域词典、查询扩展、融合参数），不存在针对 38 题中任何一题的特判规则。词典 `statute_rag/synonyms.json` 是按法律领域批量收录的「口语/缩略说法 → 法定表述」一般性映射（127 词条 / 194 个法定表述），覆盖刑事、民事、劳动、消费、行政、交通等领域，与具体评测题目无对应关系。
- **留出法自证**：每轮机制同时跑两套金标；真实金标提升的有效性以「合成金标 Recall@5 回退 ≤2pt」守门。合成金标的查询是条文中的正式书面短语，口语词典对它天然少触发，是合适的回退哨兵。
- **负结果也记录**：实测无增益的机制（法名先验加权、trigram 短语加权、替换式变体多路、更深的融合通道）一律从代码移除，记录在 §4。

## 1. 基线（改进前，R0）

| 检索器 | 真实 R@5 | 真实 MRR | 合成 R@5 | 合成 MRR |
|---|---|---|---|---|
| like（子串基线） | 0.0% | 0.000 | 77.4% | 0.774 |
| bm25（字符二元组） | 26.3% | 0.180 | 96.6% | 0.954 |
| hybrid（RRF：bm25+like 双路） | 26.3%（10/38） | 0.180 | 98.9% | 0.984 |

失败结构（逐题插桩实测，38 题中 28 题未命中）：

- **18 题「近似命中」**：金标行在 bm25 排名 6–70，词法信号存在但被同法/跨法竞争行压出 top-5；
- **10 题「零重叠」**：口语词（坐牢/看望/探视/社保/房东/噪音/丢/立案/过期/证照/吸毒/减资…）在金标条文中完全不出现，词法通道无从命中。

## 2. 机制：同义词典 + 查询扩展多路召回（最终保留）

**数据文件** `statute_rag/synonyms.json`：127 词条，形如 `"坐牢": ["服刑", "刑罚", "刑事责任"]`、`"社保": ["社会保险"]`、`"丢了": ["丢失", "遗失"]`、`"退一赔三": ["欺诈", "三倍赔偿"]`。

**扩展逻辑** `statute_rag/query_expansion.py`：

1. 前向最长匹配扫描查询串命中词典 key（只收 ≥2 字词条，避免单字误扩展）；
2. 追加式扩展：原查询整体保留，命中词的全部法定表述接到查询尾部（上限 8 词）——原查询信号永不替换、只增不改；
3. 数字读法归一：`1000元→一千元`、`10倍→十倍`、`第10条→第十条`（仅转换「数字+单位字」与「第+数字」两类，裸数字/年份不转，避免错误读法）。

**融合** `statute_rag/retrieval.py::HybridRetriever`：三路 RRF——`bm25(原查询)` + `bm25(扩展查询)`（扩展无命中时自动省略）+ `like(原查询)`；每路候选深度 `max(30, k)`（`HYBRID_FUSION_DEPTH=30` 与 k 解耦，见 retrieval.py）。查询侧 n-gram 按空格分段切分（`query_grams`），gram 不跨词边界，避免扩展查询产生「询服」类边界噪声 gram；语料侧索引与金标生成逻辑不受影响。

**为什么有效**：零重叠类失败靠扩展查询直接建立词法桥（坐牢→服刑、探视→会见、噪音→噪声）；近似命中类失败靠「金标行在扩展通道排名高 → RRF 第二票」抬进 top-5。

## 4. 负结果清单（已实测、已从代码移除）

| 机制 | 实测 | 移除理由 |
|---|---|---|
| 法名先验加权（law 字段 gram 记 0.25/0.5/0.75 权重 tf） | 真实 R@5 零增量，MRR −0.002 | 不服务目标；同法内部竞争时先验对所有同法行等量加成，无区分力 |
| 查询 trigram 短语加权（权重 0.5/1/2 扫描） | 真实 R@5 零增量 | 金标行受双栏解析污染，连续短语常被打断，加权帮不到最需要的地方 |
| 替换式变体多路（每命中词替换成法定表述单独成一路） | R@5 持平 44.7%，MRR 0.300 vs 0.312 | 无召回增量且拉低排序质量；追加式扩展已覆盖其收益 |
| 通道深度 50/100 | 真实 R@5 −1 题 | 深通道把低质量票引入融合 |
| BM25 k1/b 参数网格（k1∈{0.9,1.2,1.5,2.0}×b∈{0.5,0.6,0.75,0.9} 共 16 组合，单路） | 真实 R@5 全部 26.3% 纹丝不动，MRR ±0.01；合成金标随 k1 升高单调变差 | 排序瓶颈不在 BM25 参数；失败题要么零重叠要么被竞争行压制，调参无济 |
| 加权 RRF（扩展通道权重 1.25/1.5/2.0/3.0 扫描） | 真实 R@5 零增量（1.25/1.5 还各掉 1 题） | 排名投票对「扩展通道 rank 1 但融合 rank 12」这类近似命中无翻转力——这是 v0.2 重排通道要解的问题，不是融合加权能解的 |

### 4b. v3 语料轮新增负结果（2026-10，机制前提已变）

语料从 14,212 条扩到 25,273 条后，行长分布由单峰（公报页块，均长 1,325 字）变双峰（混入均长 105–127 字的官方单条），**上表里「零增量」的部分结论前提因此改写**：`BM25_B` 与扩展通道权重在 v3 上重新成为有效旋钮（已落地，见下节）。本轮同时实测并**未**落地的机制：

| 机制 | 实测 | 移除理由 |
|---|---|---|
| 同 `(law,num)` 去重折叠（融合排名同一法同一条只留最优代表） | 三版语料 × 双金标**逐位不变** | v3 仅 8 部法、401 个键重复，且无一落在 38 题金标上；零召回增量 |
| 同法限流（融合排名每部法最多留 N 行，N=1/2/3） | 灾难性回退：v1 R@30 78.9% → 26.3%/31.6%/44.7% | 38 题的 `gold_ids` 本身多是同一部法的 3 行，按法限流直接砍掉召回 |
| 引用行降权（「依照/根据/适用/参照…的规定」开头的行后置） | 合成金标 **−3.4pt**（v1 98.9→95.5，v3 97.2→93.8），真实零增量 | 回退守门失败 |
| `like(扩展查询)` 第 4 路通道 | 三版 × 双金标逐位不变 | 扩展串几乎不做子串精确匹配 |
| 多视图融合（同语料不同 b 的 BM25 多路 RRF） | 全部低于单 b=0.6（最佳 4 路配置 v3 R@5 39.5%） | 长度不敏感路把噪声票带进融合 |
| 长度比封顶（`len/avg_len` 封顶 1.25/1.4，b=0.75） | v1/v2 逐位不变（v1 MRR@5 保持 0.312），v3 只到 39.5%/36.8% | 方向正确但力度不足；与 b=0.6 叠加反而回退到 39.5% |
| `k1` 网格（b=0.6 下 k1∈{0.9,1.2,1.5,2.0}） | k1=0.9/1.2 使 v3 R@5 掉到 34.2%/39.5%；k1=2.0 使合成金标 97.2→96.6 | k1=1.5 仍最优，保持 |
| 通道深度加深（depth 10/20/50/80，b=0.6） | depth=30 在 R@30 上最优（65.8/68.4/71.1/73.7） | 与 v1 时代结论一致，保持 30 |
| `RRF_K` 扫描（10/30/45/60/90/120，b=0.6） | R@5 恒 42.1%，仅 rrf_k=10 使 R@10 55.3→57.9 | 零 R@5 增量，不做无依据改动 |
| 扩展词典扩容（新法领域口语词） | 未做：38 题的 miss 中**没有一道**属「有词典可桥但词条缺失」（证据见下节原文） | 新增词条只会越过通用机制边界 |

改进后新命中的 7 题（问句 → 命中位次，全部经通用词典桥接）：嫖娼可以不拘留只罚款吗（嫖娼→卖淫嫖娼，#3）、三次吸毒会被拘留多久（吸毒→吸食注射毒品，#5）、邻居半夜噪音扰民可以报警吗（噪音→噪声、扰民→干扰他人正常生活，#1）、租房押金不退怎么办（租房→住房租赁，#1）、个人租房房东不退押金怎么处理最有效（房东→出租人，#1）、公司不给交社保离职后可要求经济补偿金吗（社保→社会保险、离职→解除/终止劳动合同，#1）、公司减资股东需对公司债务承担责任吗（减资→减少注册资本，#3）。

**诚实声明**：词典为领域通用映射，但收录过程发生在看过真实金标失败分析之后——这是领域词典建设的正常顺序（先发现问题、再补通用词条），无法也不必假装词条凭空而来。防过拟合作弊的约束是：(a) 无任何按题特判；(b) 词条均为一般性法律用语映射，可独立审计（`statute_rag/synonyms.json` 全文入库）；(c) 合成金标零回退证明机制没有以牺牲正式表述检索为代价。

## 6. 剩余 21 题未命中（如实列出，按卡点归类）

1. **纯语义等价，词典无桥可搭（最深的坑）**
   - 失信被执行人会坐牢吗（金标：拒不执行判决、裁定刑事解释——「坐牢→刑事责任」的桥接在扩展通道被公司法「依法追究刑事责任」条款淹没）
   - 电动车在楼道内充电是否属于违法行为（金标：消防法疏散通道条款；问句与条文几乎零词法重叠）
   - 假货是退一赔三还是退一赔十（金标：消保条例欺诈赔偿条款；已加「退一赔三→欺诈」词条，仍被公报双栏污染行压过）
2. **同法内部竞争（多条相似条文挤占 top-5）**
   - 消费者能否解除健身房私教课等预付卡消费合同（金标解释第 13 条在第 11–15 名，同类「解除/返还预付款」条文密集）
   - 行政复议的期限是多长（整部复议法都在讲期限）；法院立案的标准及条件（起诉/受理条款分散在多部解释）
   - 食品"知假买假"10 倍惩罚性赔偿（金标第 12 条在第 4 名，同解释其他惩罚性赔偿条款环绕）
   - 开餐饮店需要办理哪些证照（许可条款 vs 食品安全法大量含「许可/餐饮」的行）
3. **跨法同题竞争**
   - 未成年人沉迷网游的限制规定（top-5 被未成年人网络保护条例包揽——该条例其实是强相关答案，但金标未收录，属金标覆盖缺口大于检索失败）
   - 商品房交付必须取得竣工验收备案表吗（城市房地产开发经营管理条例多条「竣工验收」行压过金标）
   - 理发店健身房跑路办卡能不能退（公共场所卫生管理条例的「理发店」字面行压过预付式消费解释）
4. **公报双栏解析污染放大失配**
   - 快递丢了谁负责怎么赔偿（金标行文本被串栏打断，字符二元组序列不连续，第 7→5 名之差未能越过）
   - 政府信息公开多少日回复（「回复→答复」已桥接，但金标行内「答复」被污染行稀释）；仲裁协议无效如何处理
5. **功能词/金额稀释依旧**
   - 10元过期食品怎么赔偿 / 去超市买过期食品索赔1000元（数字读法桥接了一部分，但「一千元」在扩展通道引入的票不足以翻转食品安全法内部的竞争格局）

这 21 题的公共结构是：**词法信号弱或被污染，需要真正的语义通道（v0.2 embedding + 重排）或更干净的语料（PDF 重解析）**，不是继续堆词典能解决的——继续对这 21 题补词条就越过「通用机制」的边界了，故止步于此。
